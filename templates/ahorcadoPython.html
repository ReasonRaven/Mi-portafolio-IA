Tarea 5

Juego del Ahorcado en Python

Mi primer programa con logica de juego: el jugador adivina una palabra letra por letra y va perdiendo vidas cuando falla. Todo corre en la terminal, sin librerias externas.

Ver archivo .py

De que trata

Adivinar la palabra antes de quedarte sin vidas

El programa guarda una palabra secreta y la muestra como guiones. En cada vuelta pide una letra: si la letra esta en la palabra, la revela en todas las posiciones donde aparece; si no esta, descuenta una vida. El ciclo termina cuando se completa la palabra o cuando las vidas llegan a cero.

Lo hice para practicar ciclos while, listas y comparaciones. Aunque es corto, tiene la estructura de cualquier juego: estado, entrada del jugador, regla que decide, y condicion de fin.

Codigo

ejemAhorcado.py

El programa completo son 40 lineas. La parte importante es el ciclo que compara la letra contra cada posicion de la palabra.

Python 
palabra = list("casa")          # la palabra secreta, letra por letra
n = len(palabra)
entrada = ["-" for i in range(n)]   # lista de comprension: ["-","-","-","-"]
vidas = 4
encontrado = False

print("Bienvenido al juego del ahorcado")
print(f"Cuentas con {vidas} vidas")
print(f"Estado actual: {entrada}")

while entrada != palabra:           # se repite hasta completar la palabra
    letra = input("Ingresa una letra: ")

    # Reviso TODAS las posiciones: si la letra se repite, se revela dos veces
    for i in range(n):
        if palabra[i] == letra:
            print(f"Si existe {letra} en la posicion {i}")
            entrada[i] = letra
            encontrado = True

    if not encontrado:              # fallo: se descuenta una vida
        print(f"La letra {letra} no existe, bu!")
        vidas -= 1

    print(f"Estado actual: {entrada}")
    print(f"Vidas restantes: {vidas}")

    if vidas == 0:
        print("Perdiste :(")
        break                       # corta el ciclo aunque falten letras

    encontrado = False              # se reinicia para la siguiente vuelta

if entrada == palabra:
    print("Felicidades ganaste!")

print("Game over")

Como funciona

  1. Se guarda la palabra secreta como lista
  2. Se crea otra lista llena de guiones
  3. El jugador escribe una letra
  4. Si acierta, la letra se revela; si no, pierde una vida
  5. Termina al completar la palabra o al llegar a 0 vidas

Aprendizajes

Aqui entendi por que hay que reiniciar la bandera encontrado en cada vuelta: si no lo hacia, el programa se quedaba pensando que siempre habia acertado y nunca descontaba vidas. Tambien aprendi a comparar listas completas con != en vez de ir letra por letra.
